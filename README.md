# Tarea evaluativa — Mi primera aplicación de Streamlit

Aplicación inspirada en la tarea evaluativa de la página 17 del material **U3: Dashboard Interactivos**.

## Incluye
- Área principal con título, saludo, descripción, imagen, botón y entrada de texto.
- Barra lateral con título, saludo, descripción, imagen, botón y entrada de texto.
- Respuesta visible al presionar cada botón y al introducir texto.

## Para usar en Streamlit Community Cloud
1. Sube **por separado** `app.py`, `requirements.txt` y `logo_uss_referencia.png` a la raíz del repositorio de GitHub.
2. Selecciona la rama `main` y el archivo principal `app.py` en Streamlit.
3. Si ya tienes una app conectada al repositorio, se actualizará cuando guardes los cambios.

**Atención:** si usas el mismo repositorio del proyecto de ventas, esta tarea reemplazará su `app.py`. Para conservar ambos, crea un repositorio separado para esta tarea o usa otra ruta de archivo principal en Streamlit.

La imagen del logotipo se recortó de la captura de la guía proporcionada como referencia para reproducir el ejemplo; no es un recurso oficial de alta resolución.
